# «Расписание» — веб-версия (для iPhone и не только)

Это то же приложение, что и для Android, только работает в браузере. Сервер, аккаунты и роли общие: ученик может сидеть с iPhone, а его староста — с Android, данные одни и те же.

## Что внутри папки
- `index.html` — всё приложение (адрес и ключ сервера уже вписаны).
- `manifest.webmanifest`, `sw.js`, `icons/` — нужны, чтобы сайт ставился на экран «Домой» и открывался без интернета.

Загружать нужно **всю папку целиком**, не только `index.html`.

## Как выложить в интернет (бесплатно)
Сайт должен открываться по **https** — иначе не будет работать установка на экран «Домой» и офлайн-режим. Все варианты ниже дают https сами.

**Вариант 1 — GitHub Pages**
1. github.com → New repository (например, `raspisanie`), Public.
2. Add file → Upload files → перетащи всё из папки (вместе с папкой `icons`) → Commit.
3. Settings → Pages → Source: «Deploy from a branch», ветка `main`, папка `/ (root)` → Save.
4. Через минуту-две сайт будет по адресу `https://ТВОЙ-ЛОГИН.github.io/raspisanie/`.

**Вариант 2 — Netlify или Cloudflare Pages**
Зарегистрируйся и перетащи папку в окно загрузки — получишь ссылку вида `https://что-то.netlify.app`.

Рядом можно положить и `admin.html` — тогда админка тоже будет открываться по ссылке с любого компьютера.

## Как поставить на iPhone
1. Открой ссылку в **Safari** (именно в Safari, не в Telegram и не в другом браузере).
2. Нажми «Поделиться» (квадрат со стрелкой) → **«На экран „Домой“»** → «Добавить».
3. На рабочем столе появится иконка «Расписание» — открывается на весь экран, как приложение.

На Android: открыть ссылку в Chrome → меню ⋮ → «Добавить на главный экран».

## Чем отличается от Android-приложения
- Всё то же: вход (с кодом из письма, если привязана почта), «Забыл пароль», роли, «Сегодня», «Моё расписание» учителя, «Расписание», ДЗ с файлами, Н-ки, журнал (Н и оценки ставит учитель, староста и куратор смотрят), сводка, админские «Убрать Н».
- **Напоминания:** вместо уведомления со звуком при открытии появляется плашка «🔔 На завтра есть ДЗ». Фоновые push-уведомления для сайта требуют отдельного сервера рассылки — это можно добавить позже.
- **Отметки «сделал»** у ДЗ хранятся на конкретном устройстве (как и в Android-версии).
- Без интернета показывается то, что загрузилось в последний раз.

## Обновления
Загрузи новые файлы на GitHub (Add file → Upload files → Commit). Приложение само проверяет новую версию при каждом открытии: обычно достаточно закрыть его и открыть снова через 1–3 минуты после публикации.
